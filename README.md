# Datastory

This repository contains a Jupyter Book data story about enrollment trends and future projections in Dutch higher education.

## About this project

- Team: Jens Groen, Thijs van der Meer, Sarah Kruse
- Topic: Growth and challenges in Dutch higher education
- Grading: this project was graded with an **8/10**

## Repository structure

- `docs/` – source notebooks, data files, and assets for the story
- `_config.yml` and `_toc.yml` – Jupyter Book configuration and table of contents
- `requirements.txt` – Python dependencies to build and run the notebooks

## Build locally

```bash
pip install -r requirements.txt
jupyter-book build .
```
